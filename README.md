Retail Sales & Customer Behavior Analysis

Project Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, Pandas, NumPy, Matplotlib, and Seaborn.

The objective is to analyze retail sales data, identify customer purchasing patterns, evaluate business performance, and generate actionable business recommendations.

Dataset: 3,000 synthetic retail transactions created for educational and portfolio purposes.

Tools & Technologies

* Python
* Pandas and NumPy
* SQL
* Matplotlib and Seaborn
* Jupyter Notebook
* GitHub

Business Questions

1. What is the total sales revenue?
2. Which product categories generate the highest revenue?
3. How do monthly sales change over time?
4. Which customer segments contribute the most to sales?
5. What opportunities exist to improve business performance?

Data Analysis Process

1. Data Cleaning

* Checked for missing values and duplicate records.
* Validated data types and transaction dates.
* Prepared the dataset for analysis.

2. Exploratory Data Analysis (EDA)

* Analyzed revenue and profitability.
* Examined monthly sales trends.
* Compared product categories and regional performance.
* Explored customer purchasing behavior.

3. SQL Analysis

Used SQL queries to aggregate sales, compare product performance, and answer business questions.

4. Data Visualization

Created charts using Matplotlib and Seaborn to communicate sales trends and business performance.

Business Recommendations

* Prioritize products and categories with strong profitability.
* Investigate seasonal changes in demand.
* Use customer segmentation to support targeted marketing.
* Monitor regional performance to guide inventory decisions.

How to Run the Project

1. Clone or download this GitHub repository.
2. Install Python and Jupyter Notebook.
3. Install dependencies using pip install -r requirements.txt.
4. Open the Jupyter Notebook included in the project.
5. Run the notebook cells to reproduce the analysis.

Conclusion

This project demonstrates practical data cleaning, exploratory analysis, SQL, data visualization, and business problem-solving skills using a synthetic retail dataset.
